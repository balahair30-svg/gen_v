Jurusan #1 · Software Engineering

Pengembangan Perangkat Lunak (PPL)

Fokus membekali santri keahlian rekayasa software: logika pemrograman tangguh, arsitektur basis data, clean code, serta kemampuan merilis aplikasi web full-stack yang dapat diakses pengguna di internet.

Modul Pembelajaran Utama (1 Tahun)

01. Logika & Algoritma

Pemecahan masalah, struktur data dasar, flowcharts, & pseudocode.

02. Frontend Web Modern

HTML5 semantik, modern CSS, Tailwind CSS & responsive design.

03. JavaScript & TypeScript

ES6+ modern, asynchronous programming, DOM, & type safety.

04. React.js Ecosystem

Komponen reaktif, state management, hooks, & integrasi API.

05. Backend API & Database

Node.js, Express REST API, serta PostgreSQL database design.

06. Git & Capstone Project

Version control Git/GitHub, kerja tim, & proyek aplikasi riil.
